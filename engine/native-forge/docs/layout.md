# 纸张、边注与宽对象

版式先根据正文、图表和注释的实际阅读宽度确定。原稿页面比固定模板宽时，不先缩正文；以原生文字和矢量对象完成一组包含密集注释、最长注、宽公式及宽图表的真实样张，检查实际 PDF 后再用于全书。

## 页面合同

`project.json` 可增加 `layout`。未设置时保持旧项目的入口及几何覆盖行为；已设置时在前言区应用纸张和版心，确保 PDF 的物理页面尺寸真正改变，同时同步页眉宽度。只在 `AtBeginDocument` 改纸张会使几何参数与 PDF 物理页面不一致，不能采用。

```json
{
  "layout": {
    "paper_width_mm": 240,
    "paper_height_mm": 285,
    "text_width_mm": 145,
    "inner_mm": 22,
    "outer_mm": 22,
    "top_mm": 23,
    "bottom_mm": 23,
    "margin_note_width_mm": 44,
    "margin_note_sep_mm": 7,
    "note_font_pt": 9,
    "note_leading_pt": 13,
    "notes": "outer",
    "chapter_open": "any"
  }
}
```

水平方向必须闭合：内侧边距 + 正文宽 + 注间距 + 注栏宽 + 外侧留白 = 纸张宽。本例为 `22+145+7+44+22=240mm`，原生全宽区域为 `145+7+44=196mm`。`outer_mm` 是注栏外沿到纸边的空白，并非正文到纸边的总距离。

正文保持现有 11pt。`notes=outer` 启用双面外侧注栏；奇数页右侧，偶数页左侧。页码重置须保持实体页的左右关系，不能通过任意重置计数器掩盖错误。

`chapter_open=any` 为配置版式的默认值，章节可以从任意一页开始，避免双面边注意外启用传统图书的空白隔页。明确需要每章从右页开始时设为 `right`；由此产生的空白页是已选设计，仍须在逐页检查中记录。未配置 `layout` 的旧项目不受此选项影响。

默认值为 A4、正文164mm、四边23mm、无注栏、`notes=footnote`、注字体9pt/行距13pt。未知键、非有限数值、尺寸矛盾及无有效高度均拒绝构建。无边栏时注栏宽及间距必须为零。此接口不按章节或单页偷偷改变纸张。

## 语义注释

正文标记和注释块使用稳定 ID 关联；显示编号保留原书规则，可按章重置，ID 不能重用。

```json
{
  "id": "chapter01-paragraph03",
  "kind": "paragraph",
  "source_ids": ["p0008-b0002"],
  "tex": "对应的正文句子。\\nfnotemark{chapter01-note01}{1}"
}
```

```json
{
  "id": "chapter01-note01",
  "kind": "note",
  "number": "1",
  "placement": "margin",
  "source_ids": ["p0008-b0002"],
  "tex": "原生中文注释，数学仍可使用 $x^2$。"
}
```

注释块在语义阅读顺序中紧随所属段。若抽取证据把正文和注释合为一个来源块，两者可以共享真实 `source_ids`，并在必要时留下原文片段说明；不能编造新的来源 ID。

`placement=margin` 的内容在前言区预声明，实际边注在正文 `nfnotemark` 位置进入页面队列，避免段后统一投放造成锚点错位。`placement=block` 则按块顺序显示为正文宽的补充注释，可在页面间自然断开，前方短线与编号区分主文。两者均生成正文到注释、注释返回正文的链接。

补充注释前后设置 `FloatBarrier`，阻止相邻浮动图表穿插长注的续页；注释本身保持可分页，不封装为整注 minipage。仍须检查真实页序与顶部浮动关系，不能把浮动屏障当成所有特殊页边界的视觉保证。

每条注必须有且只有一个编号一致的标记。边注标记必须位于正文段落，标题、表格、浮动体中的注用 `block`。注内不能嵌套注或浮动环境。普通行内数学可保留；长推导、宽矩阵、TikZ 以及实际高度较大的注释应先试 `block`。字符数只能帮助初筛，最终以渲染盒尺寸、可读性和页面位置为依据。

正文注号按脚注标记方式移除前置空隙并禁止在标记前断行，同时登记到 xeCJK 的不换行命令列表，防止中文自动间距留下额外断点。注号与前一个字保持相连，不通过缩小正文字号解决孤立上标。

短边注由 TeX 的 `marginfix` 排队避让，可能上下移动。长注不能依靠不断缩字或未验证的跨页边栏机制塞进去。发现跨页漂移时应调整具体注释的 `placement` 或内容邻接关系，重新构建并核验，而不是删除正文标记或忽略队列。

## 原生宽对象

公式、表格、资源图和原生图支持 `span=body|full`，缺省 `body`。`full` 使用正文加注栏的自然宽度，并在此垂直区域阻止边注占位，不会执行整体缩字或截图回退。

```json
{
  "id": "wide-equation",
  "kind": "equation",
  "source_ids": ["p0020-b0003"],
  "span": "full",
  "numbered": false,
  "tex": "a_1+a_2+\\cdots+a_{15}=b"
}
```

原生表格宜使用 `tabularx` 和当前 `\\linewidth`，较长表格保留 `longtable`。资源图仍通过 `asset` 登记；`span=full` 时按块放置并保持原生标题和来源锚点。`figure_native` 可使用 TikZ 等原生内容。全宽对象内禁止再嵌套 `figure` 或 `table` 浮动环境。窄图不需要为填满页面而放大，宽公式优先用合适的数学断行，再决定是否使用全宽。

目前未实现自动横置页面。确实超出全宽区域的对象必须先定位具体对象及语义关系，再扩展通用接口或按原生数学/表格结构处理，不得声称已有未经验证的横页支持。

## 构建与检查

构建至少执行两次 XeLaTeX；若交叉引用或严格双面全宽定位仍要求重跑，可继续到四次。仍未收敛的日志进入失败项。

`main.log` 中每个边注生成 `NFNOTE-METRIC <ID> height=<sp> width=<sp>`，尺寸单位为 TeX scaled point。`qa/layout_report.json` 已换算为毫米，包含：

- 实际纸张和声明几何。
- 每条注的正文标记、注起点、注终点的绝对页和坐标。
- 边注盒高宽、上下边界、相对正文标记的页差及垂直位移。
- 注间纵向重叠、超出版心、落入错误侧栏、跨页漂移、缺失位置/尺寸等失败项。

`marginfix` 遗失注释、超长盒和文末残留队列也会阻止技术检查通过。纵向位移会完整报告；没有人为设定一个位移阈值来代替阅读判断。全宽区域与边注之间的距离，以及正文标题、留白和注释的视觉关系仍须查看实际页面。

`layout` 与实际 `.aux` 位置记录进入构建指纹。更改任何版式、注内容、模板或位置记录都会使旧复核失效。发布包包含 `nativeforge.sty`、`qa/layout_report.json` 和 `qa/layout_positions.aux`；新增使用的 `marginfix`、`changepage`、`zref-savepos`、`zref-abspage` 为 TeX 发行版标准包，仍需在交付环境安装。

测试和合成校准样张证明接口可用，不能替代本书全部页、全部注及译文的实际复核。保留 compiled、technical_pass、reviewed、released 的区别。

## 独立标题与目录顺序

书稿开始合并、润色或美化前，应从原书目录和实际标题确定 `content.expectations.heading_source_ids`。这是按原书顺序排列的唯一来源 ID 数组，例如：

```json
{
  "expectations": {
    "heading_source_ids": ["p0042-b0001", "p0056-b0000", "p0088-b0002"]
  }
}
```

上例仅展示这个字段，实际文件仍须保留公式、图表等其他必要 expectations。每个声明 ID 必须属于当前来源包，并且恰好绑定一个 `chapter`、`section` 或 `subsection`。同一个标题块不能承担两个独立声明标题；标题的块顺序必须与数组完全一致。段落共享这些来源 ID 不能代替标题存在，未声明的辅助标题不会自动被禁止。旧项目未配置此字段时，仍沿用原有来源覆盖检查。

不得仅根据中文标题的字面相似度去重。把“对称性”与“规范对称性”，或“狭义相对论”与“广义相对论”合为一个标题，即使合并了所有来源 ID，仍会丢掉结构。本检查使这种合并在构建时失败；它不证明标题翻译正确，也不代替检查原书目录与实际章节。

## 跨来源页的语义段落

来源分页或并行chunk边界不应强迫一个完整句子在译排中断成两段。确认为同一语义段时，可给前一个 `paragraph` 块设 `join_next: true`。它只能接紧邻的下一个 `paragraph`，省略时为false。独立block ID、source_ids及来源链接全部保留。

引擎在此接缝不生成 `\\par`，并去掉接缝首尾空行，避免仅靠换行又隐式分段。类型必须是真正boolean，不能写字符串或数字；末块、跨标题/公式/浮动体，或包含显式分段/分页边界的拼接均拒绝。是否属于同一段仍须对照原文，不得用这个字段自动粘连所有相邻段落。

## 相邻续式的分页

同一推导被来源拆成两个相邻 `equation` 块时，可在第一块显式设置 `keep_with_next:true`。引擎在第一式局部设置 `\\postdisplaypenalty=10000`，并在式后输出 `\\nopagebreak[4]`，保留两个块的 ID、source_ids、公式内容和编号。仅在式后发命令不能消除显示公式结束时已有的分页点，因此两处约束须配合。字段必须是 boolean，只能用于 equation；true 时末块或下块不是 equation 均拒绝，不能跨注释、正文或标题。省略或 false 不改变原分页行为。

此字段只禁止两个显示公式之间的分页，不把整个推导封装成不可分的大盒，也不自动合并公式。确认它们确为续式后再使用；过高推导仍须按数学逻辑拆分并看实际页面。
