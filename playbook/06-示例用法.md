# 06 示例用法

> 以下是**真实会话里出现过的**命令与模板，可直接复制。
> 为满足"本包要装到别的机器"，原文中的绝对路径一律替换为占位符：
> `$NF` 引擎目录 · `$SK` 技能目录 · `$PY` 带 PyMuPDF 的 Python · `$SRC` 原稿 PDF · `$PROJ` 项目目录 · `$INBOX` 分片目录 · `$STAGE` 项目级脚本目录。

**㉖ 源页拼版（自己造审查材料的最小做法）**
```powershell
& $PY -c @"
import fitz
from PIL import Image
import io
d = fitz.open(r'$SRC')
def montage(pages, out, zoom=0.75, cols=3):
    ims = [Image.open(io.BytesIO(d[n-1].get_pixmap(matrix=fitz.Matrix(zoom, zoom)).tobytes('png'))) for n in pages]
    w, h = ims[0].size
    rows = (len(ims) + cols - 1) // cols
    sheet = Image.new('RGB', (w*cols, h*rows), 'white')
    for i, im in enumerate(ims):
        sheet.paste(im, ((i % cols)*w, (i // cols)*h))
    sheet.save(out); print(out, sheet.size)
montage(list(range(21, 31)), r'$PROJ\qa\src\sheet-21-30.png')
"@
```

## 8. worker 任务单模板

**㉘ 扫描件转写 worker（3 页，逐条约束写死）**
```text
你是「<书名>」原生中文 PDF 重建项目的转写 worker。

第一步：用 read 完整读合同 `$PROJ\WORKER_CONTRACT.md`，严格按合同执行。
第二步：转写源扫描页 <pNNNN、pNNNN、pNNNN>。
  分带图在 `$PROJ\work\slices\`（形如 `pNNNN_b0.png` 上半页、`pNNNN_b1.png` **下半页**）；
  像素范围读同目录 `slice_index.json`（b1 的图内像素行约 +730 才是整页行号）。
  用 read_image 看；一屏不清就用 Pillow 裁该带局部放大 2–4 倍。

**务必把每页的 b1 读完到页脚**（本项目已多次证实「只读 b0、下半页整段丢失」）。

其余约束：
- 只转写本页内容；**不要把本页顶部内容当成上一页的续文而跳过**；也不要把相邻页内容收进本页。
- 含粉红/红色底纹的页：红底上的黑字用「三通道 < 150」判墨；**红底白字用「R>100 且 G>100」**。
- bbox 用**整页归一化坐标**（像素 y ÷ 整页高度）；x0<x1、y0<y1。
- 证据 object 的 kind 只能取 paragraph/equation/table/figure/heading/header_footer；text 必须非空。
- 页眉页脚只作 object + `excluded_objects`，**不建 block**。
- 程序清单用 block 的 `kind="code"` + `text`（text 是清单正文本身）。
- figure 块**不写 tex**；图 bbox **不含印刷图题**；并排图各自登记。
- 表格用 `kind="table"`，**列数声明与内容列数一致**，且 block 自带 `\renewcommand{\thetable}{...}` + `\caption{...}`。
- 每个 equation 块**恰好一个 `\tag{...}`** 且 `numbered: true`；原书无编号的显示式**不加 `\tag`**；环境**绝不嵌套**。
- notes 里的反斜杠**双写**。

第三步：写出 `$INBOX\pNNNN.json`，**每写完一页立刻落盘并 `json.load` 验证**。
汇报（中文 4 行内）：objects/blocks 数、公式/图/表数、**每页 objects 的 y 上界**、剩余疑点。
```
来源：`sessions\10-计算物理-扫描件主控.md`（多份任务单合并压缩，约束原样保留）

## 9. 契约与记录的形状

**㉛ `content.json`（节选，只列关键字段）**
```json
{
  "title": "<书名>",
  "blocks": [
    {"id":"p0031-p1","kind":"paragraph","source_ids":["p0031-b0001"],
     "tex":"……\\footnote{……}"},
    {"id":"p0031-fig","kind":"figure","asset":"pfif-fig-p0031-exchange-loop",
     "caption":"","width":0.62,"source_ids":["p0031-b0002"]},
    {"id":"p0046-e2","kind":"equation","source_ids":["p0046-b0011"],
     "numbered":true,"tex":"\\begin{equation}\n...\n\\tag{2.1.11}\n\\end{equation}"}
  ],
  "exclusions": [{"source_id":"p0031-b0009","reason":"页脚"}],
  "source_notes": [],
  "unresolved": [],
  "expectations": {"equation_tags":["2.1.11"],"table_count":0,"figure_count":1,"required_strings":[]}
}
```
字段与约束来源：`references\worker-contract.md`（允许的 kind：`chapter/section/subsection/paragraph/equation/table/figure/figure_native`，边注另用 `kind:note`）

**㉟ 发布前扫未转义的 `%` 与花括号不平衡**
```powershell
& $PY -c @"
import json, re
from pathlib import Path
d = json.loads(Path(r'$PROJ\content.json').read_text(encoding='utf-8'))
bad = []
for b in d['blocks']:
    for k in ('tex', 'caption', 'text'):
        s = b.get(k)
        if not isinstance(s, str): continue
        for m in re.finditer(r'(?<!\\\\)%', s):
            bad.append((b['id'], k, s[max(0, m.start()-40):m.start()+40]))
print('unescaped % count', len(bad))
for x in bad[:20]: print(x)
for b in d['blocks']:
    if b.get('kind') == 'figure':
        c = b.get('caption', '')
        if c.count('{') != c.count('}'): print('brace imbalance', b['id'], repr(c))
"@
```
