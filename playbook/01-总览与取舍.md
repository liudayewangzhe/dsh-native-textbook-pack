# 01 总览与取舍

> 本手册只覆盖一件事：把一本**技术 PDF**（书、扫描书、课件）重建为**中文原生 PDF**——正文、公式、表格是可编辑的原生 TeX，图形按来源选择"保留矢量 / 原生重绘 / 如实保留位图"，并且每一类检查都写清它证明什么、不证明什么。
>
> 技能本体：`$SK\SKILL.md`（`$SK` = 技能目录，即 `native-textbook` 的安装位置）。
> 引擎本体：`$NF\nf.cmd`（`$NF` = Native Forge 引擎目录）。

---

## 1. 这条工作流在做什么

它不是"PDF 翻译"，也不是"OCR → 机器翻译"。真实管线是四段：

| 段 | 输入 | 输出 | 谁负责 |
|---|---|---|---|
| 来源前检 + 版式决策 | 原稿 PDF | 前检报告、版式任务单、风险样张方案 | 规划者 / 监工 |
| 转写重建 | 来源页证据（文本块 + 页面 PNG） | 带来源 ID 的语义 TeX 块（`content.json` / `chunks/*.json`） | worker（可交给受限模型批量做） |
| 组装与构建 | 全部 chunk | `build/main.pdf` + `qa/*.json` | 监工 + 引擎 |
| 复核与放行 | 成品 PDF + 原稿 | 视觉审查记录（绑定哈希）、可复编包 | 监工 + 独立审查者 |

三条贯穿全程的原则（来自 `references/workflow-gates.md` 与实测事故）：

1. **来源页 PNG 只是核验材料**，绝不作为出版正文回退；公式、表格一旦截图就违规（`engine\native-forge\AGENTS.md`）。
2. **编译成功、检查通过、模型说看过，三者不能互相替代**（`SKILL.md` §铁律）。
3. **同类缺陷不许犯第二次**：缺陷要沉淀成规则或检查器，否则下一轮必然复发（`references/slide-pitfalls.md` 就是在同一份 15 页课件上被连续指出三轮后才写出来的）。

## 2. 先锁定交付形态：book / slide / 可编辑 pptx

形态判断在**开工前**做，做错会让后面全部返工。

| 用户想要 | 走哪条路 | 判断依据 |
|---|---|---|
| 教材式连续阅读、章节重组、把课件扩写成教材 | **book**（ElegantBook + 引擎 `nf.cmd`） | 需要目录、章节层级、页码、边注、跨页接排 |
| 保留 PPT 风味的横版中文课件 PDF，一源页 = 一输出页 | **slide**（独立 XeLaTeX 链，**不走** `nf.cmd release`） | 用户明确说"保留课件样式""按页" |
| 可编辑的 `.pptx` | 路由 `office-pptx` / `presentations` 一类的演示分支 | 交付物必须是 pptx 文件本身 |
| 只要 PDF，但来源是 PPT | **slide**（book 不适用） | "来源是 PPT"不等于"必须交 PPTX" |

实测教训（`sessions\07-Lecture2-Signals-PPT双版本.md`、`sessions\09-native-textbook技能升级.md`）：

- 同一份 15 页课件**同时**做了 slide 版（保留课件风味）与教材版（ElegantBook 1 章 10 节），两者共用同一批来源证据但走**完全不相同的**版式与门禁。skill 加载顺序是 `native-textbook` → `office-pptx`。
- slide 产品锁定必须写进任务单：`slides_preserve`、1:1 页对应、4:3 比例、**不恢复动画/备注**（源是静态 PDF）、发布走独立清单而**不是** `nf.cmd release`，不得写 `nf released`。

> 形态无法从请求和证据判断时：先做完来源前检，再回来问这个差异。不要凭文件名把课件塞进书籍模板（`SKILL.md` §先锁定交付形态）。

## 3. 角色分工

`references/first-draft-and-polish.md` 的角色表，加上实测中真正出现的分工：

| 角色 | 读什么 | 交什么 | 不该做什么 |
|---|---|---|---|
| 规划者 | `source-preflight`、实际源页 | 前检报告、版式任务单、风险样张方案 | 不要求它先交一份"已通过样张"（循环门禁） |
| 排版参数确定者 | `chinese-typography` 模数阶梯、`cover-and-geometry` 几何合同 | 字号模数、行距比、版心、页脚保留区 | 不逐处试字号 |
| 绘图者 | `figure-craft` 语义合同、遮挡五类、连接拓扑 | 图的语义合同、命名锚点、遮挡/裁切自查 | 不捏造数据；不缩小正文字号迁就版面 |
| **worker**（转写/重建） | 任务单指定的页 + packet + 术语增量 | **只写**自己那份 chunk / 精确补丁 | 不动共享 `content.json`/`assets.json`/模板/`review.json`；不自填"通过" |
| **监工** | 全部证据 + 变更清单 | 合并、构建、QA、全页 L1 视觉、放行裁决 | 不替独立审查者签字 |
| **独立视觉审查者** | 成品 PDF（不参与制作） | 高风险子集的独立结论 | 不复制监工清单；结论冲突时以看图证据为准 |
| 发布者 | 门禁产物 + 复编证据 | 交付 PDF、可编译 TeX 包、验收报告（含 `limits`） | 不在有 `unresolved` 时发布 |

**worker 的上下文要给"小而完整"**（`references/first-draft-and-polish.md` §4）：一本书的通用规则由监工保持一份，worker 只收与当前块相关的部分；不要把整本书的 PNG 和长日志反复塞给它。

## 4. 什么叫"真的做完了"

这是整条工作流最容易出错的地方。四个状态必须严格区分，不能互相顶替（`references/workflow-gates.md` §2）：

| 状态 | 含义 | 能不能交付 |
|---|---|---|
| `compiled` | XeLaTeX 退出码 0 | **不能**。未转义的 `%` 能让半页正文静默消失而编译成功 |
| `technical_pass` | 页数/尺寸/越界/栅格数/字体嵌入/必需字符符合配置 | **不能**。它不证明数学、视觉、语义正确 |
| `reviewed` | 授权源页与**全部**输出页完成实际对照；审查记录绑定当前 PDF 哈希；独立审查覆盖高风险子集 | 接近，但还要过复编 |
| `released` | 当前指纹通过 `nf.cmd release`（book）/ 通过独立 slide 发布清单 | 可以 |

### 放行五阶段的就绪条件（分层，避免循环）

1. **规划可进入试排**：授权范围与现有证据齐备。
2. **同类风险样张通过**：相同配置、字体、引擎、几何下的真实样张通过 → **才放行批量**。
3. **草稿已生成**：指定范围完整，**仍可有未决项**，不称成品。
4. **技术检查通过**：构建、来源覆盖、原生对象、几何、链接通过。
5. **复核完成 → 已交付**：全源页 + 全输出页实际对照 + 独立审查 + 独立包复编。

### 交付前的硬否决条件（任一存在即不得交付）

- 存在 `unresolved` 未处理
- 有未覆盖的来源页
- 图形类型错误（该矢量却是位图、该原生却是截图）
- 编译失败或原生对象检查失败
- 有页未做视觉复核
- 审查指纹过期（PDF 已变但用旧审查）
- 检查器与渲染器不一致而未隔离原因

> 实测中最容易违反的一条：**"我以为做完了"**。`sessions\05-经典力学-主控.md` 里，288 页成品没有逐页人工目视复核，交付方**没有伪造** review 记录，所以项目状态停在 `draft`，没走 `nf.cmd release`，交付说明里如实写"技术检查通过 + 抽样视觉检查"。这是正确的做法，也是本手册推荐的默认姿势。

## 5. 一份最小的放行证据长什么样

`references/workflow-gates.md` §8 给出了必备字段。要点：

- `pdf_sha256` / `tex_sha256` / `assets_sha256` / `source_sha256`：**报告绑定的是产物指纹，不是"我做过"**
- `stage`：只能是 `compiled` / `technical_pass` / `reviewed` / `released` 之一
- `checks.visual.performed` + `l1_pages` + `l2_pages`：看没看图，看的是哪些页
- `size_check`：声明值 vs 实测值（见 `04-踩坑与注意点.md` 的 72/96 与"声明值≠实测值"）
- `limits` **必填**：不写"没检查什么"的报告视为不完整
- `unresolved` 与 `issues`：状态字段承载事实，**不迎合门禁**
