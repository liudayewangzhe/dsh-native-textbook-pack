# Scientific Visuals

Choose the output path by deliverable:

- Exploratory statistical chart: use seaborn or simple matplotlib.
- Publication figure: use matplotlib with journal-ready layout, color, typography, and vector export.
- Scientific schematic or technical graph: use diagram semantics first, then render with the appropriate tool.
- Mermaid or markdown-native diagram: use text diagrams when they are easier to review and version.
- Infographic or raster asset: use image generation only when a bitmap visual is the right artifact.
- Slides or posters: use the presentation/poster workflow and verify exported pages visually.

Always define the audience, output format, dimensions, and verification target before rendering.
