# 绘图工艺与绘图质检

本页解决"图看起来不对"的两类问题：**语义错**（箭头方向、连接关系、单位）与**几何丑**（遮挡、不连续、裁切、对齐）。

核心判断：**矢量、清晰、无重叠都只是表示属性；正确的端点、方向、交集、单位与图文对应才是语义属性。** 一幅图可以"很矢量"同时是错的。旧稿出现过：公式逐字相同的图里箭头由双向变单向、走错分支、线不接顶点、断线、根点与闭合路径缺失。

## 1. 先写语义合同，再动几何

画任何图之前，用文字列出这张图的**节点、边、方向、标签归属、坐标基准、单位/范围**。这份清单是图的规格，也是验收依据。

```text
图 5-2 冲激近似
节点：基线、矩形、三角、ε 标记、2ε 标记、1/ε 标记、轴标签 t
边  ：矩形高 → 1/ε；三角顶点 → 1/ε；矩形宽 → ε；三角底宽 → 2ε
方向：两条竖箭均向上；时间轴向右
归属：ε、2ε 属横轴；1/ε 属纵轴
基准：原点左下；时域窗 x∈[-15,17]；纵轴 y∈[-15,3]
数据：矩形与三角面积均为 1（ε、2ε、1/ε 是推理数据，不是装饰）
```

规则：

- 语义合同里**每一个箭头方向、每一个端点归属**都要写。图上"看起来像"不算锁住。
- 未知测量数据**不得重采样**。示意信号可用解析定义重绘（`plot[domain=...]`），真实实验数据必须用原始数据。
- 教学图里承担推理的数据（`ε`、`2ε`、`1/ε`、面积=1）不能省；**一个展开项最终为 0 也不能删掉来源步骤**。
- 图注/图题属于图的一部分，进图的边界计算。

## 2. 语义验收：逐条比对连接关系

示意图通过"没有重叠"检查就交付，是旧稿反复犯的错。语义验收必须**逐条**：

- 每条箭头的**起点和终点**：是不是该连的两个对象？方向对不对？单向/双向是否与源一致？
- 每条线的**端点**是否真正落在目标对象的边界上（不是"附近"）？
- 分支是否走对？有没有漏掉源图里的根点、闭合路径、辅助线？
- 曲线/面积/允许区间：形状、单调性、交点、阴影范围是否与源一致？
- 坐标轴：轴线存在、刻度、单位、正负方向、原点标记。
- 每个标签"属于谁"：标签靠近哪条线，不能因为位置相近就被归错。

**反证也要保留**：旧稿曾怀疑源图某个 `μ` 标签是错的，放大源图后确认原书如此，撤回了改动。**已撤回的错误判断不继续传播**。

## 3. 几何工艺：防止遮挡、不连续、裁切

### 3.1 线接锚点，不用裸坐标

**不连续的头号原因是两端写了未经验证的裸坐标**：节点尺寸一变（字号、文本宽度、换行），线就离开框。

```latex
% 不好：猜测坐标，节点一改就断
\draw (1.2,0.4) -- (3.4,0.4);

% 好：命名锚点，始终连到对象边界
\node[draw] (A) at (0,0) {输入};
\node[draw] (B) at (3,0) {处理};
\draw[-{Stealth}] (A.east) -- (B.west);
```

- 用 `(A.east)`、`(B.west)`、`(C.north)` 等锚点，或 `\path (A) -- (B) coordinate[pos=0.5] (mid);` 求中间点。
- 需要"离对象留一点空隙"时用 **`shorten >=2.5pt`（或 `shorten <=`）**，**不要手改坐标**。这是把箭头"收在目标边框外"的标准做法；多条箭头汇聚到同一节点时尤其必要，否则箭头尖会插进目标图形。
- 节点用 `inner sep` 控制内边距（实测项目**只用 `inner sep`，`outer sep` 用量为 0**）。理由：`outer sep` 会同时移动锚点与边框，混用会让箭头落点随对象尺寸漂移；只用 `inner sep` 时锚点始终在边界上。
- 需要箭头精确落在边框上时，给相关节点**相同的 `minimum width` / `minimum height`**，让边框位置可预测。
- 箭头尺寸用**带单位的长度**（如 `Stealth[length=2mm,width=1.4mm]`），同一组图复用同一规格，形成统一的箭尖族；不要一部分图用 `->`、另一部分用 `Stealth`。
- `dashed` 只用于构造线/辅助线。

### 3.2 标签避让

标签压在线上、两个标签互相重叠，是最显眼的"业余感"。

- 标签不要落在线的中点上，除非线在该处是空的。用 `node[above]`、`node[below left]`、`pos=0.3`/`pos=0.7` 错开。
- 标签多时**先列标签清单再排位置**，不要逐个试。给每个标签分配一个区域。
- 用 `fill=white`（或页面底色）给跨线的标签加"挖空"，这是允许的常规手法：
  ```latex
  \draw (A) -- node[fill=white,inner sep=1pt,above] {$u(t)$} (B);
  ```
- 用 `text width=2cm,align=center` 让长标签换行，而不是让它横向溢出压住别的东西。
- 刻度数字与轴标签分开层级：刻度 6–7 pt，轴名 8 pt，不要同字号。
- `\usetikzlibrary{positioning}` 的 `right=of`、`above=of` 配合 `node distance` 能得到稳定间距，比手填坐标可维护。

#### 遮挡的五类形态与检出法

"遮挡"不是一种问题。按形态分类才能定位成因：

| 形态 | 现象 | 成因 | 检出/修法 |
|---|---|---|---|
| **1. 标签压线** | 曲线/直线从标签字形中穿过 | 标签放在线中点且未挖空 | 看图放大；`fill=white` 或错开 `pos`；均匀分配标签区域 |
| **2. 标签互压** | 两个标签外框相交 | 标签位置各自独立估的，没有全局排布 | 逐对检查 bbox 相交；先列清单再排布 |
| **3. 元素冲出图区被裁** | 曲线只剩顶端、轴/刻度消失 | 图区 bbox 只算了图形没算标签/轴 | 渲染"未裁整图 + 计划框"确认；bbox 必须含轴/箭头/刻度/标签/曲线/图题 |
| **4. 文字被填充图形盖住** | 文字看不见或看不清 | 色块/横幅/覆盖层压在文字上，或文字色与填充色接近 | `check_typography.py` 的 `text_obscured_by_fill`：按填充色与文字色**对比度**分级，<2.0 判实际不可见 |
| **5. 文字互相重叠** | 两处文字外框相交 | 逐字形摆放、手工坐标、浮动体重叠 | `check_typography.py` 的 `text_overlap`（已排除数学逐字形与 ⌈⌉ 类框线字形的误报） |

规则：

- **"无重叠"不等于语义正确。** 几何干净只说明没挡住；箭头方向、连接关系、单位、图文对应是另一套检查。两者都要过。
- 自动检查只能查出形态 4、5 和部分形态 3；形态 1、2 必须靠**放大看图**。
- 排查顺序：先看整图缩略（形态 3、2），再放大看图内标签（形态 1、4、5），最后逐条对语义合同。

### 3.2b 连接拓扑合同

箭头与连接关系是**语义**，不是外观。图上公式逐字相同，箭头仍可能反向、走错分支、不接顶点。

画之前逐条写清并逐条验收：

```text
连接拓扑（示例：反馈环）
A → B   实线，单向，条件：误差 e 输入
B → C   实线，单向
C → A   虚线，单向（反馈），标注 −1
B → D   实线，单向，从 B.east 出发
```

- **方向守恒**：源图是双向箭头就不能简化成单向；源图有箭头就不能画成无箭头线段。
- **端点守恒**：每条线接**命名锚点**，禁止未经验证的裸坐标端点（裸坐标是"线不接框"的直接原因）。
- **分支守恒**：源图有几条分支就画几条；漏掉根点、闭合路径、辅助虚线都是错误。
- **标注归属守恒**：每个标签标明属于哪条线/哪个对象；不因位置相近而错配。
- **条件与单位守恒**：边上的条件（如 `−1`、增益、单位）必须与源一致。

验收方式：**逐条**比对拓扑清单与渲染结果，不靠"整体观感"。图区通过后还要在**最终整页**再看一次裁框、字号与正文关系——独立图正确 ≠ 嵌入整页正确。

### 3.2c 来源疑点：回源确认与撤回台账

审阅者也会过度修正。历史实例：旧稿怀疑源图一个 `μ` 标签是错的，建议改成 `u`；放大源图后确认**原书本身就是 `μ`**，该建议随即**撤回**。

规则：

- 任何"源图看起来不对"的判断，必须**回源放大确认**后才能改。
- 确认源确实如此 → 保持原样，不"规范化"。
- 确认是提取/裁切错误 → 修提取，不改源语义。
- **已撤回的错误判断不继续传播**：在报告里保留撤回记录（哪一条、依据什么撤回），不要让它在后续轮次里复活。
- 台账格式：`{对象ID, 原判断, 依据, 结论(改/不改), 撤回理由}`。

### 3.3 边界必须包含全部可见对象

**裁切事故的根因是 bbox 只算了图形，没算标签和轴。** 实测旧稿：顶排图区 bbox `y=14.5–25.5 mm`，而源图常数线在 `y≈29.7 mm`、时间轴在 `y≈37 mm`；底排 bbox `y=47.0–60.8 mm`，而正弦负半周延伸到 `y≈78 mm`。结果曲线、轴、大半波形全被剪掉。

规则：

- 图区 bbox **必须覆盖：轴线、箭头、刻度、数学标签、完整曲线、图题**。
- 裁剪前先渲染"未裁的整图 + 计划 bbox 框"看一张图，确认框住了所有对象。**图片资源为空不证明没有裁切。**
- 需要整体留边时，用 TikZ 的 `\useasboundingbox` 显式声明，或在图外留白，而不是靠估算坐标。
- `clip=false` 让溢出标签可见，但那样会与相邻元素重叠——**不要用 `clip=false` 掩盖边界没算对**，要先把边界算对。

### 3.3b 尺寸与缩放：绝不缩小字号去迁就版面

这是与"遮挡/裁切"并列的第二个反模式。**当图放不下时，正确做法是改布局或借空间，不是缩字号。**

实测的做法与证据：

- **放宽容器而不是压小内容**。实测：一个图若按 `width` 缩到栏宽，9 pt 的标签会被压到约 2.2 cm 的等效尺寸（不可读）。项目改用 `\resizebox{0.72\linewidth}{!}{...}` 把整图**放大 1.24×**，最终落在 11 pt 标签。方向是**放大**，不是缩小。
- 另一个项目**政策性地 `\resizebox` 用量为 0**：完全不靠缩放解决尺寸，只靠改布局。
- **宽对象借边注栏**，不缩字：用 `changepage` 的 `adjustwidth*` 向边注侧借宽度，注释写明 "No font scaling"。实测一个项目用了 **240 次**这个手段——说明"借空间"才是主力方案。
- 借空间时必须**实测盒高**，不能假设装得下：把内容先收进 `lrbox`，测 `\ht+\dp > \textheight` 就报硬错（`\PackageError`），再用 `\Needspace` 把整块推到下一页。
  ```latex
  \newsavebox{\nfWideBox}
  \begin{lrbox}{\nfWideBox}...\end{lrbox}
  \ifdim\dimexpr\ht\nfWideBox+\dp\nfWideBox\relax>\textheight
    \PackageError{mypkg}{WIDE-OBJECT-OVERSIZE}{split it semantically}%
  \fi
  ```
  这条守卫修掉过一个真实缺陷：标签被排到 `x = 645.5–671.8 pt`，而纸宽只有 `623.6 pt`（**越纸 22.2 pt**），**连编三遍都不会自愈**。
- **位图统一加载方式**。实测 176 处 `\includegraphics` **全部**用同一形式：
  ```latex
  \includegraphics[width=0.72\linewidth,height=0.78\textheight,keepaspectratio]{assets/xxx.png}
  ```
  同时给 `width`、`height` 上限并加 `keepaspectratio`，图片永远不会溢出或变形；**只有这一种适配机制**，所以也就不会形成"随手 `\resizebox`"的习惯。
- 禁止事项：`\scalebox`、`transform shape`、`\tiny` 在成熟项目里用量均为 **0**。用它们等于把"装不下"翻译成"变小/变形"，而问题通常应该用换行、重排、分面板或借栏解决。

### 3.4 多面板对齐

多面板不齐是"图看起来乱"的主要来源。

- 面板位置用**网格变量**，不要逐面板填魔数坐标。定义 `\def\dx{42}`、`\def\dy{31}`，用 `scope[shift={(2*\dx,\dy)}]`。
- 同一行面板的**基线/轴位置必须一致**；同一列面板的**左边界必须一致**。
- 共享轴的图只画一次刻度标签；不共享就不共用轴范围（这会误导读者）。
- 面板间距一致（行距/列距各自固定），图注对齐到面板或整图，**全图统一一种对齐方式**。
- 面板内字号比正文小 1–2 pt 且**各面板一致**（实测课件图内 7.3–8 pt）。

**面板身份（panel identity）三件套**——让面板之间无法互相漂移：

1. **`\useasboundingbox` 锁定整组画布**。若不锁，某个面板里一个伸出的标签会把该面板的边界撑大，于是这个面板在整组里的位置/比例被悄悄改变。实测一个项目用了 8 次。
   ```latex
   \useasboundingbox (0,0) rectangle (12,6);   % 先声明整组画布
   ```
2. **`\foreach` + `scope[shift=...]` 按平移复制面板**。"before / after"这类对照面板用平移绘制，而不是重抄一遍坐标——重抄必然产生细微偏差。
   ```latex
   \foreach \dx/\lab in {0/before, 6/after}{
     \begin{scope}[shift={(\dx,0)}]
       ... 同一套绘图代码 ...
       \node at (3,-1) {\lab};
     \end{scope}
   }
   ```
3. **`\clip` 放在 `scope` 内**裁剪自由曲线到该面板的框内，避免一条手绘曲线越出面板压到相邻面板。`\clip` 要跟着面板作用域，不要用全局 `clip=false`。

另外：TikZ 作为显示数学的矩阵行时，用 `baseline={(0,0)}` 固定基线，否则该行会随图形高度浮动。

### 3.5 线宽、箭头、颜色的统一表

**统一的目标是"同一张图（或同一组图）内一致"，不必强求全书一个样式表。** 实测成熟成品的做法是：在 `\begin{tikzpicture}[...]` 的选项里内联定义短名样式，**同一组图复用完全相同的一行选项**：

```latex
% 同一组多面板图，逐字复用同一行选项——这是实测成品保持一致的真正做法
\begin{tikzpicture}[font=\footnotesize,every node/.style={inner sep=2pt},
  ar/.style={-{Stealth[length=1.8mm]}},
  gar/.style={-{Stealth[length=2.6mm]},line width=1pt,black!60}]
  ...
\end{tikzpicture}
```

其中 `ar` 是常规箭头、`gar` 是强调箭头（更长 + 更粗 + 灰色）。实测同一组 5 个面板的选项行**完全逐字相同**，因此线宽/箭头天然一致。

**实测发现：两个成熟项目的 `\tikzset` / `\tikzstyle` 用量都是 0。** 它们的统一不是靠全局样式表，而是靠"同一组图逐字复用同一行选项" + 共享宏包。这比全局样式表更耐改，也不会因一次全局改动波及所有图。

推荐顺序：**组内逐字复用 > 共享宏包 > 每图手写新数**。共享宏包里可定义颜色名（如 `structurecolor`）让图形引用颜色名而不是写死十六进制值，换配色时全图同步。

反例（实测成品里的问题）：不同图各自内联写 `Stealth[length=1.2mm]`、`1.3mm`、`1.5mm`、`2mm`，肉眼就能看出粗细不一。

**另一条更硬的实测结论：`outer sep` 用量为 0。** 两个项目统一**只用 `inner sep`**。这样更安全：`outer sep` 会同时移动锚点与边框，混用会让"箭头落点"随对象尺寸漂移；只用 `inner sep` 时锚点始终在边界上，箭头自然落在边框。若确需空隙，用 §3.1 的 `shorten >=`，不要改 `outer sep`。

**`transform shape`、`clip=false`、`let..in`、`\scalebox`、`\tiny`、`max width` 的用量也都是 0**——这些"缺失"本身就是防护：没有 `transform shape` 就不会出现文字被一起缩放；没有 `clip=false` 就不会用"允许溢出"掩盖边界没算对。

线宽层级用**线宽 + 灰度**表达，不要靠颜色数量：

- 主轴 0.6–0.8 pt；一般轴线 0.23–0.4 pt；辅助/虚线 0.2–0.3 pt 且灰或点线。
- 实测参考：常规箭头 `Stealth[length=1.8–2.4mm]`，强调箭头 `2.6mm` 且 `line width=1pt`；曲线 `line width 0.65–1.1pt`。
- **`dashed` 只用于构造线/辅助线**，不用于表达数据含义；同一图内虚线只表示一种意思。
- 同一图内线宽层级不超过 3 档，每档差别要看得出来（≥1.5 倍）。
- 颜色只是编码，不是装饰。一个图里**系列色 ≤5 个**，且各图同一含义用同一颜色。

### 3.5b 坐标轴怎么画：优先纯 TikZ 手绘，不要上 PGFPlots

实测两份成熟成品的 `pgfplots` 加载数为 **0**，`\begin{axis}` 为 **0**——这些成品**根本没有用坐标轴环境**，轴线、刻度、标签都是手工 `\draw` + `\node` 排的。

为什么值得照做：

- `pgfplots` 的 `axis` 环境自带默认刻度密度、`enlarge limits`、标签放置与裁剪行为。对**教学示意图**（波形、势能曲线、状态图）而言，这些默认值经常造成刻度标签互相压、或标签被轴框裁掉——正是"遮挡/越界"缺陷的主要来源。
- 手工画轴时刻度位置与标签位置都在你的控制下，**对齐与间距是显式的**，容易一次做对也容易核查。
- `pgfplots` 适合**真实数据绘图**（大量采样点、自动缩放、对数轴）。示意曲线不值得为它引入一整套默认行为。

结论：**教学示意图用纯 TikZ 手绘轴线与刻度；只有真实数据集才考虑 `pgfplots`，且必须显式设置刻度密度与标签间距。**


### 3.6 颜色与对比

- 线条和文字对底色的对比度要够：正文文字对底色对比度 **≥4.5:1**（脚本按 <2.0 判"实际不可见"）。
- 不要用纯红/纯绿区分仅此一对的语义（色盲安全）；改用"颜色 + 线型/形状"双编码。
- 灰阶打印要能区分：同一图的两条曲线不能只靠"红/绿"区分。
- 图形里的文字色不要与图形填充色接近——这正是 `check_typography.py` 的 `text_obscured_by_fill` 检查项。

## 4. 原生性判定：不要凭后缀宣布矢量

- **PDF/SVG 容器不证明内部是矢量。** 检查实际可见的 image occurrences 与资产职责。
- 资源字典里的共享图片数**不等于**每页实际显示次数。实测原稿第 5 页正弦曲线本身是 `891×667 PNG`（xref=168），而 `get_images` 每页共享 64 个图片、`get_image_info` 实际 occurrences 为 45。
- `1×1` 内联色块、分数线不算教学图片；**图片数量不得解释成教学图数量**。
- 把 PNG 包进 SVG/PDF **不会**转成矢量。
- 真实照片可以保留（按来源与项目政策登记）；示意信号应原生重绘曲线、轴与标签，并验证其数学形状与教学关系。
- 渐变判定不能只看图片资源列表：部分渲染器把 shading 报成运行时图像，须查实际 PDF 对象与内联图像。

## 5. 绘图质检清单

**一句话判据：图只有三个字要过 —— 无压字、无穿线、无越界。** 实测项目就用这三个词作为图形的验收结论。逐条展开如下。

**可量化的下限**（实测项目采用的阈值）：

- 相邻标签的**中心距 ≥ 2.5 个汉字宽**。小于这个值就要重新排布标签，而不是缩字号。
- **箭尖到标签的间隙 ≥ 0.10 TikZ 单位**。箭头压到文字上是最常见的低质表现。
- 标签与线**不得相交**（"穿线"）；标签之间不得相交（"压字"）；任何对象不得越出图框或纸张（"越界"）。

**编译侧同时门禁**（四个桶必须全空，才算图形的技术检查通过）：

```text
OVERFULL   过满盒（横向/纵向溢出）
MISSING_CHAR  缺字（含 nullfont 字形消失）
UNDEFINED  未定义引用/命令
FATAL      致命错误
```

并配一个**精确相等**的栅格图计数断言（例如期望 21 张就必须 `== 21`，不是"≤ 上限"），以及运行期原生对象代理计数为 0。用"≤ 上限"会掩盖"少了 5 张图"这种漏放。

**反模式明写出来**：**不缩小正文来掩盖问题**（未缩小正文来掩盖问题）。同样地，不缩小图内字号来掩盖装不下。

**继承规则**：后一次构建只有在**同尺寸、同色彩空间（csRGB）、alpha=False、120 dpi 的原始像素 SHA-256 完全一致**时，才允许继承前一次的检查结论。并且——**文字抽取只用于定位，从不替代视觉检查**。

做"缩略图看整图"和"放大看图内标签"两种看图。

**语义**
- [ ] 箭头方向、端点归属逐条比对源图
- [ ] 无漏箭头、漏根点、漏闭合路径、漏辅助线
- [ ] 曲线形状/单调性/交点/阴影范围与源一致
- [ ] 轴线、刻度、单位、正负方向完整
- [ ] 每个标签归属正确；推理数据（ε、1/ε、面积）齐全
- [ ] 没有擅自改动源符号；疑点单独记录

**几何**
- [ ] 线与对象真正相接（锚点，不是裸坐标）
- [ ] 箭头不扎进节点、不留缝（`shorten` 统一）
- [ ] 无标签压线、无标签互压；标签中心距 ≥ 2.5 汉字宽；箭尖间隙 ≥ 0.10 单位
- [ ] 边界覆盖轴/箭头/刻度/标签/曲线/图题
- [ ] 多面板行列对齐；共享轴只标一次；`\useasboundingbox` 已锁整组画布
- [ ] 线宽、箭头尺寸、字号、颜色组内统一（选项行逐字复用）
- [ ] 图内字号 ≥ 正文的 0.75 倍，且各面板一致
- [ ] **没有靠缩小字号/缩放来塞进版面**（宽对象应借边注栏或重排）
- [ ] 文字对底色对比度足够；灰阶下仍可区分

**合入后**
- [ ] 在**最终页**再检查一次裁框、字号、与正文关系（独立图正确 ≠ 嵌入整页正确）
- [ ] 图与图注同页；没有被浮动体推到无关位置
- [ ] 该图所在页没有把正文末句挤进页脚保留区
- [ ] 资产被改动后，复核所有引用它的页
- [ ] 编译四个桶（OVERFULL/MISSING_CHAR/UNDEFINED/FATAL）全空
- [ ] 栅格图计数**精确相等**，且运行期原生对象计数符合预期

## 6. 常见症状定位表

| 症状 | 先查 | 修法 |
|---|---|---|
| 箭头不接框、线断开 | 两端是否裸坐标 | 改命名锚点；`shorten` 调间距 |
| 箭头扎进节点内部 | `outer sep`、`shorten` | 统一 `outer sep` + `shorten >=2pt` |
| 标签压线/互压 | 标签是否都落在中点 | 分配标签区域；`pos`、`above/below`、`fill=white` |
| 曲线/轴只剩顶部 | bbox 是否只算了图形 | 重算 bbox 含标签与轴；看未裁整图 |
| 边缘标签被裁 | 边界与 clip | 扩边界或改用 `\useasboundingbox` |
| 多面板不齐 | 面板坐标是否手填 | 改网格变量；对齐轴/左边界 |
| 同图线宽不一 | 是否每图内联写箭头尺寸 | 统一到 `\tikzset` 命名样式 |
| 线太密看不清 | 线宽层级是否够 | ≤3 档；主/辅线宽差 ≥1.5 倍 |
| 图字号偏小读不清 | 图内字号 vs 正文 | ≥0.75×正文；必要时重排而不是缩 |
| 文字看不见 | 文字色与填充色对比 | 对比度 <2.0 必须改色；勿用同色系 |
| 图"有点像但不对" | 语义合同 | 逐条比对节点/边/方向，不看"整体观感" |
| 打印后两条曲线一样 | 只靠颜色区分 | 加线型/标记双编码 |
| **图内文字比正文小很多、读不清** | 是否"装不下就缩字" | 改布局/借边注栏/换行/分面板；**不要缩字号**，必要时把整图放大 |
| **字号种类突然变多**（如 8 种 → 30 种） | 内容被逐帧缩放到框里 | 回到统一字号阶梯，按阶梯改正 |
| **图在最终 PDF 里成了位图、或明显模糊** | 是否被栅格化/重采样 | 检查运行期 image occurrences；示意曲线用原生 TikZ 重绘，不要从小位图放大 |

## 7. 生成与检查工具

- 简单示意：TikZ / PGFPlots 直接画，用解析定义生成曲线。
- 化学结构：`chemfig`，逐图核对立体化学与反应条件。
- 数值图：原始数据或明示精度的数字化数据；禁止重采样未知随机数据。
- 需要保留的源矢量资产：从原 PDF 取对象，确认**完整轴线/箭头/曲线/刻度/标签**后再用。
- 取资产示例（引擎）：`nf.cmd asset --project "项目目录" --page 24 --bbox x0 y0 x1 y1 --name f12`；重绘示例：`nf.cmd redraw --project "项目目录" --spec "图形规范.json" --name f12-native`，支持 `xy_plot`/`flowchart`/`tikz`/`chemfig`，生成可编辑绘图 TeX、真矢量 PDF 与来源/代码指纹。
- 排版侧通用检查：`python scripts/check_typography.py --pdf "项目\main.pdf" --mode book`（会报文字与填充图形重叠、纸外对象）。
