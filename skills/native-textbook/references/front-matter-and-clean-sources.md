# 前置页与"干净 LaTeX 源"

本页处理两类以前没被单独写下来的情况：

1. 用户授权范围**从第 1 页开始**，于是任务主体是前置页（题词、书名页、版权页、献词、目录、分部扉页），而不是正文。
2. 源 PDF 是 **LaTeX/pdfTeX 原生输出**：公式是文字层里的真数学（有 CMMI10/CMSY10/PazoMath 等数学字体、正文页 `imgs=0`），不是截图。

判据（三个数字即可分流，见 `bitmap-math-sources.md` 的对照）：字体直方图**有数学字体**、图像面积分布集中在 `>=200k` 且数量极少、抽取文本公式位置**有字符**。命中这三条就走"干净源"路线，不要做位图公式重建。

## 1. 先确认开本，再动版面

干净源常常是小开本（实测一本 199 页的书：432×648 pt = 152.4×228.6 mm，正文栏仅 106.8 mm，外侧留边注栏）。**不要把 6×9 的书直接塞进 A4 模板**，也不要在没问过用户的情况下改开本。

- 保留原开本：版心、边注栏、页眉都要重设，工作量在版面而不在翻译。
- 改 A4 重排：必须**先问用户**，并说明边注怎么办（改脚注是最常见的答案）。用户同意后再动手，不要自行决定。

一条实测：A4 + ElegantBook 默认模板的正文实测 10.9 pt、段首缩进 21.8 pt（= 2 字宽），符合中文规范；不需要为了"像原书"去调字号。

## 2. 前置页的分解与做法

一本书的前 20 页里，真正要译的正文往往只有 6–8 页，其余是空白叶与扉页。逐类处理：

| 原书部件 | 做法 |
|---|---|
| 题词页（epigraph） | 引文用**正文体**、署名右对齐。原书若用字距拉开的全大写（`T H E G O A L S H O U L D...`），抽取结果是字符间带空格，必须先归并成正常大小写再译 |
| 书名页 | `titlepage` 环境手写；作者、原书名、丛书名、插图者各占一层 |
| 版权页 | 保留原书版权行/版次/唯一标识；**另加一段"中文版说明"**，写明据哪一版译出、本册包含哪些页、边注如何处置、页码以哪一版为准 |
| 献词 | 居中短句，`\thispagestyle{empty}` |
| 目录 | **必须手工重排**。`\tableofcontents` 只会列出本版已译内容，无法承载"原书目录"；用 `\dotfill` 手工排，并在标题下注明"页码为原书页码" |
| 分部扉页 | `\clearpage\thispagestyle{empty}` + 手工大字 + 原书题词；**不要用 `\part`**——`\part` 的版面与题词位置跟原书不一致，且引擎会把 `\part` 包进 `\chapter{}` |
| 空白叶 | 见下一节 |

目录是这一段里最容易被判为"差不多"的对象，也是最能验证忠实度的对象：**用重复页码做回归**。实测例：原书 4.4.1 与 4.4.2 同为 97 页、附录 A 与 A.1 同为 141 页；译文若把重复项各少一次，就说明用了集合而不是多重集，漏了条目。

## 3. 零文字叶必须显式登记为空白

引擎 `prepare` 之后，任何**零文字块**的页都会在 `build` 时报错：

```
source page N has zero text evidence: write hash-bound source_inventory.json
```

这不是障碍，是要求你**证明**它是空白，而不是抽取失败。先确认项目采用哪种来源维护模式：直接清单模式由主控写 `source_inventory.json`；已采用 `inbox/pNNNN.json` 分片模式的项目，把判断写回对应分片并重新 merge，不能直接修改随后会被覆盖的物化清单。下例是两种模式最终都须生成的清单形状：

```json
{"schema_version":1,"source_sha256":"<与 project.json 一致>",
 "pages":{"2":{"blank":true,"checked":true,"reason":"渲染原页确认整页无文字、无图形、无图像"}}}
```

`blank` 必须同时有 `checked:true` 与非空 `reason`，且该页不能有 objects/text。**如果没有先渲染看一眼就登记，等于把抽取失败伪装成空白页。**

注意区分两种页：
- 整页无任何对象 → `blank`；
- 有文字但只是"本页故意留白"之类声明 → 不是 blank，把该块放进 `exclusions`（`out_of_scope`）。

## 4. 干净源的抽取坑（都会污染译文）

| 现象 | 根因 | 处理 |
|---|---|---|
| `ﬁnance`、`ﬂow`、`oﬀ` | PDF 里的连字字形（U+FB01…） | 统一映射回 `fi/fl/ff/ffi/ffl` 再译；否则中文里会夹生僻字 |
| `T H E G O A L` | 标题/题词用字距拉开 | 归并连续单字母为一个词，再还原大小写 |
| `Sold to xxx@yyy.com`、页码水印 | PDF 商店的销售水印，不是书稿内容 | 排进 `exclusions`（`extraction_artifact`），**绝不译进正文** |
| 页脚页码、页眉章名混入文本块 | 与正文同层 | 按 y 坐标或"纯数字/重复串"规则剔除，进 `exclusions` |
| 边注被并进正文段落 | 边注与正文同一 y 带 | 按 x 坐标分流（实测：外侧边注在 x≈29 或 x≈317，正文在 36–339），再按字号（边注 8 pt vs 正文 10 pt）确认 |
| 超长十六进制串（唯一 ID、哈希）断行失败 | `\allowbreak` 后面紧跟字母会连成未定义控制词 `\allowbreakfc` | 用零宽胶做断点：`\hspace{0pt}` 分组插入；或在 `\ttfamily` 里每 16 字符插一次 |

## 5. 交付前的最小门禁（本类任务实测）

1. `nf build` 通过；`nf qa` **status: pass、findings: 0**。
2. `check_typography.py` error=0；正文缩进实测 = 2 × 正文字号。
3. **位图计数为 0**（干净源 + 全 TikZ 图的情况下）；有任何位图必须有登记理由。
4. 关键专名、年份、版次、唯一 ID **逐项回源核对**（用脚本断言，不靠眼看）。
5. 目录页码**按多重集**核对，重复项不能丢。
6. 独立复编：完整源码包（含 `main.tex`、模板与实际资产）解到另一个空目录，用相同引擎编译**三遍**；新 PDF 与交付 PDF 页数、尺寸、逐页渲染 `.samples` 字节和书签 `get_toc()` 相等，核对源与资产哈希。文本逐字比较作为额外检查，不能替代像素和书签判据；完整门禁见 [workflow-gates.md](workflow-gates.md) §4。

第 6 条的辅助做法：分别抽取两份 PDF 的全部文本拼成字符串比 sha256，可补充发现文本差异；文本相等仍不能证明裁切、图形、位置或书签一致。
