# 封面页与页级几何

本页给出**封面构成**与**页面几何合同**：四边距、页眉带、正文区、页脚保留区，以及"声明值 ≠ 实测值"的复刻判据。

背景：这是历史成品的弱项——封面"能看但不够精致"，页边距与带区没有写成可复刻的合同，字号只写在模板里却没人验证实际渲染值。实测发现：**模板声明的字号与实际渲染的字号不一致**（见 §4），所以"照模板数字写"不能证明达标。

## 1. 封面页

### 1.1 必须包含的信息

按优先级，缺一项都要向用户确认是不是有意省略：

| 元素 | 必要性 | 说明 |
|---|---|---|
| 主标题 | 必须 | 书名/课程名；中文为主 |
| 副标题 | 视来源 | 原书有才排；不要自造 |
| 作者/编者 | 必须（书籍） | 中文译名 + 原文（首次出现） |
| 机构/出版社 | 视来源 | 原书有才排 |
| 版本/年份 | 视来源 | 课件的学年、书籍的版次 |
| 装饰元素 | 可选 | 横线、色块；**不要自造与内容无关的图形** |

**规则：源稿有什么就排什么。** 源封面没有的美术元素不要加；源封面有的（校徽、出版社标、装饰线）不要省。源有而无法获取的位图，如实登记，不用替代图形冒充。

### 1.2 构成与留白比例

竖版书籍封面（A4/B5 等），纵向分三段：

```text
┌─────────────────────────┐  ← 上边距 ≈ 纸高 18%–22%（上部留白）
│ ═══════════════════════ │  ← 可选：细分隔线（约占版心宽，不顶到纸边）
│                         │
│        主标题            │  ← 主标题上沿约在纸高 27%–32%
│                         │
│        副标题            │  ← 距主标题 ≈ 0.7–1.2 行主标题行距
│                         │
│      （中部留白）         │  ← 纸高 25%–35%，是"设计感"的来源
│                         │
│   作者 / 机构 / 年份      │  ← 下区，底部基线上方 ≥ 纸高 8%
│ ═══════════════════════ │  ← 可选：下分隔线
└─────────────────────────┘  ← 下边距 ≈ 纸高 10%–15%
```

关键要求：

- **上部留白要大于下部留白**（18–22% vs 10–15%）。上下等距会显得"被框住"。
- **中部留白是刻意的**，不要为了"填满"把作者信息往上推或加装饰。封面的呼吸感来自这块空。
- 主标题**最多 2 行**；超过就缩字号或改短，不要压到 3 行。
- 主标题与副标题的**字号比 1.35–1.8**（实测一份成熟成品为约 1.38：主标题约 13.5 pt、副标题约 9.8 pt）。比小于 1.3 会像两行正文。
- 主标题用书名/H1 级字号（见 [chinese-typography.md](chinese-typography.md) 模数表）。

### 1.2b 对齐方式与装饰元素

对齐方式由源封面决定，两种都常见，**不要混用**：

- **左对齐**（科技书常见）：主标题、副标题、作者、机构全部对齐同一条左基线；上下可各加一条细分隔线（宽度约等于版心，不顶到纸边）。实测成熟成品即此形态：上分隔线约在纸高 21%，主标题约 27%，副标题约 31%，作者约 41%，下分隔线约 93%。
- **居中**（教材/课件常见）：所有元素水平居中，通常不加装饰线。

规则：

- 分隔线用**细线**（0.4–0.6 pt）且颜色克制（深灰或主题色的低饱和度版本）；线宽不一或颜色跳脱比没有线更糟。
- **源封面有什么就排什么**：源封面没有的美术元素不要加；源封面有的（校徽、出版社标、装饰线）不要省。源有而无法获取的位图，如实登记，不用替代图形冒充。
- 作者/机构用中文 + 原文首次标注（如 `雅各布·施维希滕贝格　著 / Jakob Schwichtenberg`）。
- 出版方/版本信息可放在下区靠下位置，字号比作者小 1–2 pt。

### 1.3 横版课件封面（slides_preserve）

课件封面**沿用课件母版**，通常不画页眉带与页脚带：

```latex
% 空标题 → 不画标题带（这是母版契约，不是省略）
\Slide{}{ }{%
  \node[anchor=center, font=\fontsize{15}{19}\selectfont]
       at (64, 40) {\color{titlered} EG2302：系统动力学与控制};
  \node[anchor=center, font=\fontsize{9.5}{13}\selectfont]
       at (64, 52) {莱斯特大学};
}
```

- 主标题居中于页面（横版通常 `x = 纸宽/2`，`y ≈ 纸高 × 0.42`）。
- 副标题在主标题下方 **1.2–1.4 倍主标题行距**处。
- 页脚带按母版决定是否画；封面一般不画页码。
- 实测课件封面：主标题 15 pt / 行距 19，副标题 9.5 pt / 13；外框用双层圆角矩形做投影（`black!14` 偏移 + `white` 内层）。

### 1.4 空标题 = 不画带

模板契约：**标题为空就完全不画标题带**，不能用空格冒充标题（会产生一条空灰条，很显眼）。

```latex
\if\relax\detokenize{#2}\relax\else
  \fill[headgray] (0,3.13) rectangle (128,13.03);
  \T{title}{3.4}{5.5}{121}{14.2}{\color{titlered}#2}
\fi
```

源稿本身没有可见标题的页（历史实例：第 7、9 页源本无标题，第 5 页标题被白色图块遮盖），必须**如实登记**，不能补造标题，也不能因为"应该有标题"就加上去。

### 1.5 封面不被 worker 重复绘制

母版（`\Slide` 宏）负责顶带、标题带、页脚。**内容 worker 不得再次绘制标题/顶带/页脚节点**——历史事故：worker 自加了六行 `*-title`/`*-hdr` 节点，与母版叠在一起，由监工删除后记为问题 1。

任务单里显式写清"母版画什么、worker 画什么"，并在合并时核对对象归属。

## 2. 页级几何合同（课件）

实测一套可复用的 4:3 中文课件几何（128 × 96 mm = 362.83 × 272.13 pt）。用**毫米网格**表达，编译后必须回抽实测校验。

| 区域 | 位置 | 高度/尺寸 |
|---|---|---|
| 页面 | 128 × 96 mm，`margin=0mm` | — |
| 顶带（左红右灰） | y 0 – 3.13 mm | 3.13 mm |
| 标题带 | y 3.13 – 13.03 mm | 9.90 mm |
| 标题文本 | x 3.4 mm，y 5.5 mm，宽 121 mm | 14.2 pt，`titlered` |
| **正文区** | x 3.4 – 124.5 mm，y 18 – 88 mm | 高 70 mm |
| 页脚带（三段） | y 93.3 – 96 mm（0–42.3 / 42.3–85.3 / 85.3–128） | 2.70 mm |
| 页脚文本 | y 94.6 mm，四项 | 4.8 pt |

坐标系统：`tikzpicture[remember picture, overlay, x=1mm, y=-1mm]` + `scope[shift={(current page.north west)}]` → **左上角原点、y 向下、单位 mm**。所有对象坐标都能直接对着这张表核对。

正文区硬约束：

- 任何正文/公式/图的**外框**（含积分上下限、根号、矩阵、分数的高度）必须落在 y 18–88 mm 内。
- 页脚 y 93.3–96 mm 是**保留区**，末句与公式不得伸入。
- 标题带下沿（13.03 mm）到首个正文对象（18 mm）留 4.97 mm ≈ 1.5 × 正文字号——这就是"首行贴着标题条"那条缺陷的量化边界。

## 3. 竖版书籍页面几何

书籍用 `geometry` 明确写出，不要依赖模板默认：

```latex
\usepackage[
  paperwidth=170mm, paperheight=240mm,
  inner=22mm, outer=18mm, top=22mm, bottom=20mm,
  marginparwidth=26mm, marginparsep=3mm   % 有边注时
]{geometry}
```

- **内外边距不等**（装订侧 inner 更大），不是左右等距。
- 有边注时：正文宽 + 间隔 + 边注宽 + 内外边距 = 纸宽，**必须闭合**。用实测值验证，不靠估算。
- 正文可读行长：中文每行 **30–50 字**（按正文宽度 ÷ 字号算）。实测两份成熟成品分别为 **48.07 字/行**（623.6 pt 页宽，正文栏 56.7–476.2 pt，栏宽 419.5 pt）与 **37.68 字/行**（680.3 pt 页宽，正文栏 206.9–618.0 pt，栏宽 411.1 pt）。超过 50 字读起来会串行，需要加宽边距或分栏。
- 上下边距比例：上边距略大于下边距（如 22 : 20），视觉更稳。

实测两份成品的栏结构（可直接对照）：

| 项目 | 经典力学 优化版 | 金融物理 精排版 |
|---|---|---|
| 纸张（pt） | 623.6 × 807.9 | 680.3 × 807.9 |
| 结构 | **双栏**：正文 56.7–476.2 + 边注 56.5–102.2 | 边注 57.3–187.1 + 正文 206.9–618.0 |
| 正文栏宽 | 419.5 pt | 411.1 pt |
| 左右额外留白 | 9.09% / 6.82% | 30.41%（左，含边注区）/ 9.16% |
| 每行中文字数 | 48.07 | 37.68 |
| 正文 / 数学 / 西文字号 | 10.91 / 10.88 / 10.91 pt | 10.91 / — / — |
| 页码字号 | 9.96 pt | — |
| 章标题（一级） | 17.22 pt | — |

### 字体分工（实测字面占比）

成熟成品的字体使用是**分工**而非单一字体：

| 用途 | 经典力学 占比 | 金融物理 占比 | 建议 |
|---|---|---|---|
| 中文正文 | SimSun 59.2% | SimSun 69.4% | 宋体系作正文载体 |
| 数学 | NewCMMath-Regular 23.3% | NewCMMath-Regular 10.9% | 交给数学宏包，不要手设 |
| 西文/数字 | TeXGyreTermesX 13.4% | TeXGyreTermesX 14.3% | 与 Times 族匹配 |
| 强调/标题 | SimHei 1.0%、YaHei 0.7%、KaiTi 0.03% | SimHei 0.8%、KaiTi 0.6% | 中文强调用黑体或楷体，占比 <1% |

配置示例：

```latex
\setCJKmainfont{SimSun}                 % 中文正文
\setCJKsansfont{SimHei}                 % 中文标题/强调
\setmainfont{TeX Gyre Termes}           % 西文与数字
% 数学字体由 unicode-math / newtxmath 等宏包决定，不在此手设
```

注意：**中文与数学的实测字号常常差一点**（实测中文 10.91 pt、数学 10.88–10.91 pt 基本一致；但课件实测中文 9.46 pt、数学 9.96 pt 差约 5%）。这是字体字面高度不同造成的，属正常，不要为了"对齐"去改其中一个。

## 4. 声明值 ≠ 实测值：复刻判据

**这是本页最重要的一条。** 实测发现模板里写的字号和最终 PDF 里的字号并不一致：

| 元素 | 模板声明 | 实测 | 偏差 |
|---|---|---|---|
| 封面主标题 | 16 pt | 14.94 pt | −6.6% |
| 正文（中文） | 9.5 pt | 9.46 pt | −0.4% |
| 正文（同页数学） | 9.5 pt | 9.96 pt | +4.8% |
| 正文行距 | 13.3 pt | 15.6–15.9 pt | +17%~+20% |
| 课件源正文行距 | 4.87 mm ≈ 13.8 pt | 成品 15.6–15.9 pt | 成品比源松约 13% |

原因不止一个：CJK 字体的实际字面率、`\fontsize` 与 `\selectfont` 的组合、`\linespread`/`\baselineskip` 的交互、数学字体自带尺寸、`setspace` 类宏的影响。**所以"照模板数字写"不能作为达标证据。**

因此必须把「回抽实测比对」写成硬门禁：

1. 从**源**截图/抽取得到目标字号清单（如正文 9.96 pt、标题 14.35 pt、页脚 4.98 pt、上下标 6.97 pt）。
2. 编译后从**实际交付 PDF** 抽取 `(字号, 文本)` 对。
3. 逐条比对：**同尺寸来源原则上应复刻**；偏差超过 **±3%** 判为失败，先查原因再决定是接受还是修。
4. 把该结果写进技术报告，而不是写"模板参数已设置"。

这条门禁能自动拦住历史上最严重的版式事故：整册字号被乘 72/96（正文 9.963 → 7.512 pt，缩小 25%）。同一族的问题还有"声明 13.3 实测 15.9"这种**行距比源松 13%** 的隐性偏差——单看页面觉得"还行"，与源并排就有差别。

命令：

```powershell
# 1) 交付 PDF 的字号直方图与按字号行距（事实）
python scripts/check_typography.py --pdf "项目\build\main.pdf" --mode slide --report qa\typo.md

# 2) 源 vs 交付 PDF 逐级回抽比对（门禁）
python scripts/compare_typography.py --source "原稿.pdf" --target "项目\build\main.pdf" `
  --mode slide --report qa\size-compare.md --out qa\size-compare.json
```

`compare_typography.py` 的输出里最重要的是 **`body_scale_ratio`（正文字号整体比例）**：
≈0.75 就是典型的 72/96 整册误缩，≈1.0 说明整体尺度保持。它还会逐级列出字号偏差、
未配对层级和行距比偏差。默认 `--scale auto`：检测到"外文源 → 中文目标"时自动放宽
到 ±10%（中文正文字号天然可略小于源，字面率不同）；同语言重排用 ±3%。

实测校准：用该工具比对英文原稿与合格中文课件，**0 告警**；比对英文原稿与失败稿，
报出 `第1级 -25.0%`、`第4级 -25.2%`、`global_scale 0.75`、以及行距比 1.5→2.0（+33%）——
四项共同指向"整册缩小且行距未同比缩小"。

## 5. 单位与坐标铁律

同一份文档里混用单位是几何错误的根源。逐层标清：

| 层 | 单位 | 换算 |
|---|---|---|
| PDF / TeX | pt（1 pt = 1/72 in） | `mm = pt × 25.4 / 72` |
| 页面/几何合同 | mm | 1 mm = 2.834646 pt |
| PPTX | EMU | 36000 EMU/mm |
| CSS px / raster dpi | 显示层 | 只在预览层换算 |

铁律：

- **PDF 抽取出的 span 字号就是 pt，不乘 72/96。**
- 页面 bbox 标明坐标系与原点（PDF 常规是左下原点；TikZ 层用左上原点，必须在合同里写明是哪一个）。
- 源 PDF 左上点坐标 → 指定裁区 → 资产自身原点 → 目标页坐标：**每一层只改变一次坐标系**，注明 pt/mm、缩放、翻转、裁切原点。
- 整页出现约同倍放大/裁切时，先用**无文字无公式的四边标记矩形**校准反馈工具，再对比真实导出的 PDF；不要靠缩放内容去迁就未校准的渲染器。

## 6. 交付前几何自查

- [ ] 封面：上下留白比例（上 > 下）、主副标题字号比 1.35–1.8、主标题 ≤2 行
- [ ] 封面：全部元素同一对齐基线（全左或全中，不混用）；分隔线细且颜色克制
- [ ] 封面元素与源一致；源没有的没加，源有的没省；缺失位图已登记
- [ ] 空标题页确实没有标题带；源无标题的页没有补造
- [ ] 课件：正文外框全在 y 18–88 mm；没有伸进页脚保留区
- [ ] 课件：正文区到标题带留 ≥1.5 正文字号
- [ ] 书籍：内外边距不等；正文+边注+边距总和 = 纸宽（实测验证）
- [ ] 每行中文 28–42 字
- [ ] 回抽实测字号与源比对，偏差 >±3% 的项已查因或列为未决
- [ ] 实测行距与源比对；行距比异常升高已排查
- [ ] 单位逐层标注；没有 pt/mm/px 混用
- [ ] 母版/内容对象归属明确，没有重复绘制标题带或页脚
