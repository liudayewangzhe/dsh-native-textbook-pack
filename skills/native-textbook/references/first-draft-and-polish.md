# 从第一次生成就控制质量

本手册把排版判断拆成可检查的动作。先读本页；只在遇到相应风险时读其他详细参考。目标是减少带缺陷的批量初稿和整书返工，不要求一次读完所有规则。样例尺寸、页数和某本书的用词都不是通用默认。

## 先确定当前角色和任务

| 当前任务 | 先读/做什么 | 本轮交什么 |
|---|---|---|
| 新文章/新书的规划者 | source-preflight；实际源页；本页的决策和试排步骤 | 来源前检、版式任务单、待执行的风险样张方案、规划阶段 worker 任务单；试排通过后再生成批量任务单 |
| 保留 PPT 风味的原生 PDF 制作者 | source-preflight；[slide-native-pdf](slide-native-pdf.md)；[slide-worker-contract](slide-worker-contract.md)；[cover-and-geometry](cover-and-geometry.md) | 页级内容与几何合同、真实风险样张、独立 slide 构建/检查/发布证据 |
| 翻译/转写 worker | 监工给的任务单、当前完整小节、术语表增量、worker-contract | 有来源ID的指定chunk；不确定项；不自行发布 |
| 排版参数确定者 | [chinese-typography](chinese-typography.md) 的模数阶梯与留白下限；[cover-and-geometry](cover-and-geometry.md) 的几何合同 | 字号模数表、行距比、版心与页脚保留区、封面构成；写入任务单 |
| 绘图者 | [figure-craft](figure-craft.md) 的语义合同、遮挡五类、连接拓扑 | 图的语义合同、命名锚点几何、遮挡/裁切自查、回源疑点台账 |
| 草稿尾处理者 | 原交付说明作历史事实；当前PDF、内容/资产清单；layout-and-polish | 精确修改建议、修改后构建、完整输出页复核 |
| **视觉审核者** | [visual-audit](visual-audit.md)：两级分辨率、逐对象清单 | 接触表与高倍页图、绑定当前PDF哈希的审查记录、`limits` 与 issues |
| 监工/发布者 | 变更清单、自动检查、原稿与渲染页；[workflow-gates](workflow-gates.md) 的证明边界 | 接受/拒绝理由、当前指纹的review、可复编包、真实覆盖范围 |

任务单没有来源范围、写入路径或允许修改的对象时，先补齐；不能让 worker 猜。用户只是给文档用于特征研究时，到前检和规划就结束，不转成翻译授权。

就绪条件按阶段区分：规划只需授权范围和现有证据，可列待补信息；试排需该小节的可核验来源、对象ID、候选版式和确切输出路径；批量制作才要求同类风险样张已通过。不能要求规划任务先交一份已通过样张，形成循环。最终交给worker的是填好真实路径与范围的单份任务单，不能只复制通用清单。

## 1. 观察，不凭文件名选择模板

运行只读前检，然后看候选实际页面。为每个判断保留页码、区域/对象及截图路径。文字层、图片数量、横向比例只是线索。

| 看到的证据 | 需要确认的问题 | 处理决定与核验 |
|---|---|---|
| 无文字层、大幅整页图 | 是扫描、真正空页还是提取失败？有歪斜、透字、手写吗？ | 先建对象清单和阅读顺序，再按正文/数学/表/图转写；无可用OCR不能编造已识别内容 |
| 有文字层但数学乱码/重影 | 文字能否与页面对应？ | 抽查字形/上下标；数学按页面转写，不能把编码乱码当原文 |
| 正文旁有窄栏 | 注释、并列正文、图例还是教师批注？ | 确认归属与锚点；短注外侧、长宽注邻近可分页块；并列正文不能误吞为注 |
| 原稿宽、双栏、多面板 | 整页都需宽，还是只有少数对象？ | 前者选全书版式；后者保留正常行长，只扩展对象或语义拆分 |
| 幻灯片/课件 | 用户要连续教材、保留课件风味的PDF，还是可编辑PPTX？阅读顺序、覆盖动画、备注、图文分组是什么？ | 教材走book；课件PDF走slide-native-pdf；PPTX走presentations；只有PDF时不声称恢复动画/备注 |
| 大量代码/输出 | 哪些是程序、提示符、结果和行号？ | 源代码字符逐字保留；解释另译；代码换行不能改变语义 |
| 化学结构、反应路线 | 楔线/虚线、箭头条件、官能团、题号是否完整？ | 使用支持的chemfig/矢量流程；逐图核对立体化学和反应条件 |
| 方形图/链接很多 | 是二维码、普通标志还是装饰？目标是URL、内部页还是附件？ | 保留对象及目标；本地解码前后比对才能确认二维码；内部/外部/文件动作分别验收 |

未知写“待核实”和下一步，不补成貌似完整的判断。代表页由风险覆盖决定，可一页覆盖多种风险；不固定挑首页、中间页、末页，也不拿空白版权页作为试排通过依据。

建议方法不能升级为唯一前提。扫描页需要经过核验的识别/转写办法，OCR、视觉转写、人工整理可依可用证据选择；OCR未配置本身不禁止其他可靠方法。局部宽对象也不默认使用full：先量外框与标签、目标字号及可用宽，比较正常栏、逻辑拆行/拆面板和full，再选路线。摘要中的representative_candidates字段通常给代表页码，不能读成该类内容的页数；引用时写“原第N物理页”，计数只取明确count字段。

## 2. 把版式决定写成任务单

先定阅读用途和交付形态，再选纸张。下面的章节/版心说明用于book：没有特别要求时保持原书的层级、图文关系、注释归属和论证顺序；中文扩展可改变分页，不强求英文页码一一对应。slide按已锁定的页对应和显示区域设计，具体要求读 [slide-native-pdf.md](slide-native-pdf.md)。

任务单须写下实际配置或已验证模板名，并回答：

- 正文、内边距、外边距、注栏、栏间隔各多宽？总和是否等于纸宽？双面偶数页和奇数页的外侧是否正确？
- 正文字号/行距、注字号/行距、标题层级、段首缩进、段前后距、图前后距用哪个统一设置？若沿用模板，指向当前模板及其hash；不要在各chunk里重新定义。
- 最宽公式、最宽表、最复杂图、最长注各采用什么路线？为什么能读清？保留比例后的字和线是否仍可辨认？
- 源标题、公式/题目/图表编号和注号如何核对？目录/索引是原页还是本版页，链接如何验收？

先选一个内容适配的方案并试排，失败才改相关参数。不要同时改变纸张、全局字号、行距和全部图宽，这会丢失原因。book避免每页硬塞newpage、负vspace、局部缩字来“凑齐”；章节起始或原版有意留白可以保留并记录。slide的显式页界是产品结构，不属于这种书籍补丁。

中文正文使用统一中西文间距和标点禁则。过疏先查强制换行、短行两端对齐、窄盒和手写空格；过密先查行距、行内高公式、缩放和字体替换。不要用全局拉大字距掩盖个别短行，也不要把表格/公式压成截图。

## 3. 先通过真实风险样张，再扩量

从本次原稿选能覆盖已确认风险的完整小节或连续段，使用将来批量生成的同一配置与对象路线。样张必须包含正常正文作为行长和节奏参照，不能全是特殊图。

按这个顺序检查：内容和关系完整 → 数学/表/图原生表示正确 → 编译与几何检查 → 看真实页面。出现不可确认的公式/缺内容，先解决内容；字号、留白再漂亮也不能放行。

逐个风险写“源页/证据 → 采用的办法 → 构建文件/hash → 实际观察结果/剩余问题”。失败保留原记录，只改有关对象或规则再试。样张通过仅允许按这个方案扩量，不等于全书验收。更换版式/字体/对象路线后，受影响样张须重新检查。

可用引擎的 `scripts/plan_document.py scaffold/check` 建立和校验 `layout-plan.json`，具体命令见引擎 `docs/document-plan.md`。这个门禁核对结构、文件、hash和待办状态；它无法代替看图和学科判断。

## 4. 给 DeepSeek 一个小而完整的工作包

book每批按完整语义小节拆，不按固定页数截断证明或半句话。slide每批按完整页面或同一页组拆，不截断一页内的图文/推导；使用专用课件合同。计划和通用规则由监工保持一份；worker 只收与当前块相关的部分。

```text
任务：翻译转写 / 指定项尾处理（选一个）
只读：当前来源页、packet、必要前后文、术语增量、已通过同类样张
只写：本批独立输出路径；禁止覆盖共享content/assets/template/review
范围：源ID与页码；前后文仅供理解，不重复产出
已锁定：术语、符号、编号、版式、图形路线；列出当前涉及项
当前风险：源证据；已验证修法；仍不确定项
输出：符合worker-contract的JSON，或id/old_tex/new_tex/reason精确补丁
自检：源ID覆盖、正文连续、数学/数字/命令不变、图注/脚注完整
异常：写unresolved和证据，不猜，不标完成
```

不要把全书所有PNG或长日志反复发给worker。先在本地提取ID、问题摘要和相关片段；难以辨认的页面再交监工看图。对于重复失败，复用上一轮已接受输出，只重试失败项。缓存必须绑定源hash、规则/模板hash和当前输入，不能凭文件名复用过期结果。

首次批量输出先验证JSON、精确旧值、允许字段、来源覆盖及数学/编号守恒，再合并。高风险公式、科学术语、图的关系和疑似原书错误必须回源，不能因两个模型意见一致就接受。语言润色不授权变更科学结论。

## 5. 尾处理按症状定位，避免整书重写

| 症状 | 先查什么 | 常用修法 | 必须复核 |
|---|---|---|---|
| 注栏拥挤、注漂到下一页 | 实测注高/宽、锚点、其他注占位 | 改该注为邻近可分页块或调整项目栏宽 | 全文不丢、标记同页、注尾不穿插后续图 |
| 文字从高矩阵中腰穿过 | 是否把aligned/矩阵塞在行内 | 保留数学内部，改独立显示 | 前后句连续、等号/编号无变化 |
| 连续等式分到两页 | 是否是一个推导被源块拆开 | 紧邻equation显式keep_with_next | 前式无大空白、两式同页、未连接无关公式 |
| 注号独占一行 | 注号宏与CJK断行边界 | 统一禁断行宏 | 窄行、列表末尾和页底的实际截图 |
| 图片插进半句话或续注 | 浮动队列、源chunk断句 | 先合语义段；注前后屏障；必要时固定该图 | 图的语义位置、跨页续读、相邻页留白 |
| 超宽公式/图越界 | 固定宽盒、标签伸出、缩放后字号 | 逻辑拆行、full跨度、图内标签重新布局 | 奇偶页外侧、注栏占位、所有标签 |
| 标题丢失或重复 | 是否按相似标题去重 | 用有序heading_source_ids核对身份 | 实际源标题、目录、书签，不只看计数 |
| 大片空白或孤零尾行 | 章起页、不可分盒、强制分页、列表间距 | 保留有意留白；解除不必要整块锁页 | 前后页阅读顺序与内容守恒 |
| 索引/页眉错位 | 星号章、旧页码、命名目标 | 显式更新页眉；区分原页和本版链接 | 目录/索引点入实际目标 |
| “原生”检查与渲染器不一致 | XObject/内联图像/shading及来源证明 | 查实际对象；不能凭get_images为空豁免 | 运行时对象、资产来源、最终视觉 |

只要是跨书可复现的失败机制，就更新参考规则并加最小回归样例；特定公式内容、作者笔误、某条箭头方向和某书尺寸留在项目。别把个案字符串替换或本书页码写成全局修复。

## 6. 放行证据分开记

1. 规划可进入试排：方案、来源证据及待补项明确；试排所需来源、对象ID和输出路径齐备。同类风险样张实际通过后，才放行批量制作。
2. 草稿已生成：指定范围完整，仍可有明确未决项，不称为成品。
3. 技术检查通过：构建、来源覆盖、原生对象、几何及链接检查通过。**`technical_pass=true` 仍禁止交付**——它不证明数学、视觉或语义正确。
4. 排版几何检查通过：`check_typography.py` 无 error（越纸、文字重叠、不可见文字、行距异常）；字号由交付 PDF 回抽与源比对，偏差 >±3% 已查因或列为未决。见 [cover-and-geometry](cover-and-geometry.md) §4。
5. 复核完成（内容+视觉）：授权源页与**全部**输出页完成实际对照与逐对象看图；独立审查者覆盖高风险子集；审查记录绑定当前 PDF 哈希并写明 `limits`。见 [visual-audit](visual-audit.md)。
6. 已交付：book 当前指纹通过引擎 release；slide 通过独立发布清单，且资源包脱离工作目录可复编（另一目录、3 遍编译、逐页逐像素相等、书签相等）。见 [workflow-gates](workflow-gates.md) §4。

不能用“编译成功”“检查脚本通过”“模型说看过”互相替代。**每个检查的证明边界见 [workflow-gates](workflow-gates.md) §1**；越界引用检查结论（例如用"文字可提取"证明数学正确）视为造假。改善工作流的收益以实际错误减少和可重复样张证明，不承诺每种模型都达到相同质量，也不编造token节省百分比。
