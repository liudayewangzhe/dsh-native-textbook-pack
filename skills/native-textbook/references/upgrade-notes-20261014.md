## 关键实测数字（可复算）

### 决定"看起来精致"的共享前导（`nativeforge.sty`，139 行）

从成品资源包里读出的真实共享宏包，是本轮最有价值的单点发现。它把"差一点"变成了显式参数：

| 决定项 | 实际设置 | 为什么重要 |
|---|---|---|
| 数学 | `unicode-math` + `\setmathfont{NewCMMath-Regular.otf}` | 避开 Type1/PUA 路线：旧路线的数学大定界符会抽成 **PUA 私用区字符**（实测英文原书 378/140 个），公式**不可搜索、不可复制**；用 NewCM 后此类字符为 **0** |
| 浮动体间距 | `\textfloatsep 13pt plus 3pt minus 2pt`、`\intextsep 11pt…`、`\skip\footins 14pt…` | 用弹性 glue，避免"图放不下"变成硬冲突 |
| 浮动比例 | `\topfraction 0.9`、`\bottomfraction 0.8`、`\textfraction 0.1`、`\floatpagefraction 0.8`；`topnumber 3`、`bottomnumber 2` | 放宽比例让版面自然填满，减少大洞 |
| 孤行寡行 | `\clubpenalty/\widowpenalty/\displaywidowpenalty = 10000` | 对"近空白页/孤立尾行"最有效的单点修复 |
| 断行 | `\emergencystretch 2em` | 中文行内公式多，显著减少行末大空洞 |
| 版心 | `top/bottom/left/right = 23mm`，`headsep 5mm`，`footskip 10mm` | 引擎对带 layout 元数据的项目会覆盖此值 |
| 项目符号 | 用 TikZ 实心圆路径替换上游字符 | 上游球形 shading 被 XeTeX **栅格化**；改路径后全文档保持零栅格图像 |
| 边注 | `marginfix` + `zref-savepos`，注 9/13 pt，`\nfBlockNote` 带 `\FloatBarrier` | 边注是真原生文本并实测盒高；溢出转 block |
| 注号防碰撞 | `\xeCJKsetup{NoBreakCS+={\nfnotemark}}` + `\ifhmode\unskip\nobreak\fi` | 同时解决注号与前一字连排/碰撞 |
| 整宽对象 | `changepage` 的 `adjustwidth*` 借边注栏宽，**不缩放字号** | 宽对象不用缩字解决 |
| 物理书内容 | `cancel` / `ulem` | 抵消项与删除线是**内容**，不是装饰 |

### 课件版式与绘图工艺（4:3 中文课件实测）

三种课件（英文原稿 / 合格精修版 / 失败稿）**页面尺寸完全相同**（362.83×272.13 pt = 128×96 mm）——**几何从来不是问题，引擎和工艺才是**。

| 第 13 页积分 | 上下限完整 | 打印成 `ₗ₉₂.₀₂₀` |

**绘图工艺的硬结论（可当规则直接抄）**：

- 两个成熟项目里 **`pgfplots` 加载数 = 0、`\begin{axis}` = 0**——坐标轴全靠手工 `\draw`+`\node`。教学示意图不用 axis 环境，避免其默认刻度密度与裁剪行为制造标签互压/越界。
- **`\tikzset`/`\tikzstyle` 用量 = 0**：统一靠"同一组图逐字复用同一行 tikzpicture 选项"+ 共享宏包，而不是全局样式表。
- **`outer sep` 用量 = 0**（统一只用 `inner sep`）；`transform shape`、`clip=false`、`let..in`、`\scalebox`、`\tiny`、`max width` 用量也都是 **0**——"缺失"本身就是防护。
- **绝不缩小字号去迁就版面**：一个项目量出"按栏宽缩会把 9 pt 标签压到约 2.2 cm"，于是改用 `\resizebox{...}{!}` **放大 1.24×** 落到 11 pt 标签；另一个项目 `\resizebox` 用量为 **0**，全靠借边注栏（用了 **240 次** `adjustwidth*`，"No font scaling"）。
- **借空间要实测盒高**：先收进 `lrbox`，测 `\ht+\dp > \textheight` 就硬报错，再 `\Needspace` 推下页。这条修掉过标签 `x=645.5–671.8 pt` 对纸宽 `623.6 pt` 的 **22.2 pt 越纸**，且**连编三遍不自愈**。
- **位图统一加载**：176/176 处 `\includegraphics` 都是 `width=<frac>\linewidth,height=0.78\textheight,keepaspectratio`，是全项目**唯一**的适配机制。
- **标签工具**：`anchor=` 消除中心锚点半宽偏移；`fill=white` 给标签加底衬防线条穿字；`pos=0.50` 钉在路径上；`text width=`+`align=center` 防长中文标签撑破图宽；`minimum width/height` 让箭头准确落在边框。
- **箭头工具**：`shorten >=2.5pt` 防箭尖插进目标节点；`Stealth[length=2mm,width=1.4mm]` 用带单位长度形成统一箭尖族；`dashed` 只留给构造线。
- **面板工具**：`\useasboundingbox` 锁整组画布防面板漂移；`\foreach`+`scope[shift=]` 按平移复制对照面板；`\clip` 放在 scope 内。
- **图形验收判据**：一句话 **无压字 / 无穿线 / 无越界**；可量化下限为**标签中心距 ≥2.5 汉字宽**、**箭尖到标签间隙 ≥0.10 TikZ 单位**。
- **编译门禁**：四个桶必须全空（`OVERFULL` / `MISSING_CHAR` / `UNDEFINED` / `FATAL`），栅格图计数用**精确相等**（如 `21 == 21`）而非上限，运行期原生对象代理计数为 0。
- **继承规则**：只有同尺寸、csRGB、alpha=False、120 dpi 的**原始像素 SHA-256 完全一致**才可继承旧检查结论；**文字抽取只用于定位，从不替代视觉检查**。
- **明写的反模式**：**不缩小正文来掩盖问题**。

## 未做的事（如实记录）

- 没有做随机对照实验，**不给出"错误率下降百分比"**之类的量化结论。
